# 🎓 LASU Aggregate Score Calculator 2026/2027
**Developed by Afolabi Samuel Oluwaseun (LAMP EDTECH)**

A specialized tool for Lagos State University (LASU) aspirants to calculate their screening scores based on the 2026/2027 admission formula.

## 📊 Admission Formula Logic
The system computes the aggregate as follows:
- **JAMB Component:** $JAMB\_Score \times 0.15$ (Max 60 points)
- **O'Level Component:** Best 5 relevant subjects (Max 40 points)
  - **A1:** 8 pts
  - **B2:** 7 pts
  - **B3:** 6 pts
  - **C4:** 5 pts
  - **C5:** 4 pts
  - **C6:** 3 pts
